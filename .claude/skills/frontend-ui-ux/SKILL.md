# Frontend UI/UX

The interface should feel like a finished commercial game.

## Design principles

Use:

- strong typography
- clear hierarchy
- consistent spacing
- restrained color palette
- purposeful animation
- responsive layouts
- accessible controls

## Avoid AI-generated UI patterns

Do not:

- overuse gradients
- use excessive glassmorphism
- put everything inside cards
- use random icons
- add unnecessary dashboard widgets
- use excessive glow
- create decorative elements without purpose

## Main screens

Potential screens:

- Main Menu
- Mission Select
- Mission Briefing
- Terminal
- Mission Results
- Inventory
- Upgrades
- Achievements
- Settings

## Responsive design

Support:

320px+
tablet
desktop

No horizontal page overflow.

Touch targets should be comfortable.

## Interaction

Every visible control must work.

Never create fake buttons.

If functionality isn't implemented:

disable the control and explain why.

## Accessibility

Support:

keyboard navigation
focus states
sufficient contrast
reduced motion
semantic controls
screen-reader-friendly labels
